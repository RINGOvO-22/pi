# 第一阶段：`packages/ai` —— 模型能力层

## 这一层解决什么问题？

`packages/ai` 解决的是：

```text
如何统一调用不同 LLM？
```

它是 Pi 项目的 LLM SDK 适配层，负责把不同模型和 provider 的差异隐藏起来，为上层 Agent Runtime 提供统一接口。

## 可以如何理解？

这一层不关心 Agent 如何循环，也不关心具体应用形态。

它主要负责：

```text
给定 context + tools → 调用模型 → 返回 assistant message / tool calls
```

## 学习重点

重点理解以下概念：

- provider：OpenAI、Anthropic、Google Gemini 等模型服务商。
- model：具体模型。
- Context：一次模型调用所需上下文。
- Message：LLM 可理解的消息结构。
- Tool：可被模型调用的工具定义。
- ToolCall：模型请求调用工具。
- ToolResult：工具执行结果。
- stream：流式返回模型输出。
- token / cost：调用成本统计。

## 阅读时带着这些问题

1. 一个 LLM 调用需要哪些输入？
2. 不同 provider 的接口差异是在哪里被抹平的？
3. tool calling 在统一接口中是如何表达的？
4. 流式输出有哪些事件类型？
5. 最终 assistant message 是如何形成的？

## 学完后应该能回答

- 如何定义一个 tool？
- 如何构造一个 context？
- 如何调用模型并流式读取结果？
- 模型请求工具调用时，返回的数据结构是什么？

## 这一层和下一层的关系

`packages/agent` 会基于这一层提供的能力，构造 Agent Loop：

```text
packages/agent 调用 packages/ai 的 streamSimple / stream 能力
```

也就是说：

```text
packages/ai 负责单次模型调用
packages/agent 负责多轮 Agent 循环
```
