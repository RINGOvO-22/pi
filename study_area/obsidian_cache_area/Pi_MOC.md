# Pi MOC

#pi #agent #coding-agent


## 学习主线

> 会用 pi 干活 → 让 pi 更懂你 → 让 pi 适配你的系统

## 第一章：使用 pi agent 完成代码任务

目标：从零开始，用 pi 完成真实开发工作。

可细分主题：

- 安装、更新、登录
- 选择模型
- 交互模式
- 文件引用：`@file`
- 让 pi 读代码、解释代码
- 让 pi 修改代码
- 运行命令：`!command`、`!!command`
- 调试错误
- 写测试
- 常用命令：`/model`、`/new`、`/resume`、`/tree`、`/compact`
- 安全习惯：先分析、再修改、检查 diff、限制工具
